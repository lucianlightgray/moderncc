## Design questions

- Revisit reducing the compound AST nodes — FetchOffset, Assign, Cast, Call, InitList, If and Decl, each folding several source constructs behind mode flags — to smaller atomic parts, weighing fewer node kinds with branchy overlapping lowerings against more kinds with one clean lowering each, and deciding per node where the line sits.
- Prototype lowering `#define`, `#if` and `#include` expansion to executable C staged through `-run`, so the preprocessor metaprogram is represented in the CST and AST and optimized by the template layer instead of being interpreted in `mccpp.c`, in the manner of Terra and Zig.
