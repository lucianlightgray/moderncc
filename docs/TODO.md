## Slice cache and the whole-AST JIT

- Align JIT and AOT arena normalization so a JIT-written proven ident matches an AOT-shaped ident, since cross-mode proven hits are not guaranteed in practice today and this is what makes graduation only unit-proven.
- Build a per-slice optimizer that finds something the from-scratch downstream re-emit would not independently rediscover (per-slice gate search, strength reduction under a gate the downstream mask omits), because today folding a captured slice finds nothing so the promotion gate correctly rejects and the splice branch is never exercised live.
- Add per-slice `mccjit_bench_pair` micro-bench tuples; per-slice currently uses the static gate while whole-function benching lives in `mccjit_lazy_search`.
- Chain a slice's hash into enclosing scopes, callers and KGC slots so re-optimizing one propagates upward and re-patches every dependent.
- Wire the splice primitive into the AOT in-place emit path, given that `ast_func_end`'s replay re-emits from three whole-function ordered cursors recorded at capture and splicing a differently-shaped subtree desyncs them.
- Ship one arena per module instead of per-function intents, keeping a function index as a view over it.
- Define slice identity purely from the boundary — the values entering and leaving the sub-slice with widths normalized, plus internal node shape — with no `fn_name`, no parameter ordinal and no source location.
