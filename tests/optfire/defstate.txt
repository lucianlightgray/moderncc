# argfwd's GATE defaults on (o4 || optimize>=2) but the pass is INERT: it lives
# in the replay-time graft path, disabled while MCC_AST_INLINE_PASS is on, which
# it is from -O2. So toggling it changes nothing and this asserts "off" as a
# TRIPWIRE -- if the graft-path guard is ever fixed this cell fails and should
# be flipped to "on".
argfwd|-O2|arg-forward|off
indirect_call|-O2|replay-indirect-call|on
# The four rungs that came off the in-development ladder onto a settled level.

# optslice_below is the same source one level down: opt-slice sits at 3, not 2,
# and this is what says so. Without it the row above passes at any level <= 3.

# fmov-imm lowers a float constant to an FMOV immediate instead of a literal
