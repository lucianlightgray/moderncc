# argfwd's GATE defaults on (o4 || optimize>=2) but the pass is INERT: it lives
# in the replay-time graft path, disabled while MCC_AST_INLINE_PASS is on, which
# it is from -O2. So toggling it changes nothing and this asserts "off" as a
# TRIPWIRE -- if the graft-path guard is ever fixed this cell fails and should
# be flipped to "on".
argfwd|-O2|arg-forward|off
indirect_call|-O2|replay-indirect-call|on
# The four rungs that came off the in-development ladder onto a settled level.
# Each row pins the level the rung landed on: the cell fails if the pass stops
# firing there, and the mccopt.h row is the only thing that decides it.
# promote-leaf-callee was measured a pessimization on the kernel corpus (-0.34%
# of emitted instructions overall, poly -2.3% and regpress -5.6%) and moved from
# 2 to 3, so -O2 must now see it off and -O3 on. Both rows, because either one
# alone passes at the wrong level.
promo_leaf_callee_below|-O2|promote-leaf-callee|off
promo_leaf_callee|-O3|promote-leaf-callee|on
# opt-slice came OFF the shipped ladder to level 9. It cost 96% of the stage-1
# self-compile for no measurable gain on either workload, and it is what made
# -O3 codegen depend on the contents of ~/.cache/mcc (tools/opt-cache-
# determinism.py). Both rows say it is off at the top of the shipped ladder.
optslice|-O3|opt-slice|off
optslice_below|-O2|opt-slice|off
# fmov-imm lowers a float constant to an FMOV immediate instead of a literal
# pool load; ast_fmov_imm_env is compiled to 0 off arm64, so the gate cannot
# fire anywhere else and the case is registered on arm64 only.
fmov_imm|-O1|fmov-imm|on
# The rows the -O ladder measurement moved. Each pins BOTH sides of its new
# boundary, because a single row passes at any level at or below the one it
# names. tests/optfire/levelbench.tsv and selfhost-levelbench.tsv carry the
# numbers each move was made on.
chainstore|-O3|chain-store|on
chainstore_below|-O2|chain-store|off
select|-O3|if-conversion|on
select_below|-O2|if-conversion|off
range|-O3|tree-vrp|on

# builtin-math-prepass earned -O1 (efficiency 3.04) and is MASKED BY
