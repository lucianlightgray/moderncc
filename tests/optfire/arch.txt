#   #if MCC_CONFIG_OPTIMIZER && (X86_64 || ARM64 || RISCV64)
# so i386 has NO promotion code at all and these cannot fire there by
# construction. riscv64 IS compiled in but has no leaf (caller-saved) pool by
# design, so some of these still will not fire there -- that is a CASE-shape
# issue to fix when riscv64 is wired, not a reason to drop it from this list.

# opassign: the GATE is not arch-scoped (its consumers sit outside the promotion
# #if), but this CASE's observable effect is promotion-MEDIATED -- opassign flips
# functions to faithful so promotion can act on them. Measured on x86_64: with
# MCC_AST_PROMOTE=0 forced, toggling OPASSIGN produces a byte-identical object.
# So on i386, which has no promotion machinery at all, this case cannot show the
# gate working however correct the gate is. Guarding the CASE, not the gate.
opassign|x86_64,arm64
