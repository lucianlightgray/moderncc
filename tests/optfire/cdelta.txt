# <name>|<olevel>|<--stats counter>|<gate flag>
# Counter-DELTA mode: assert the counter is 0 with the gate forced off and
# nonzero with it on. Stronger than differ mode and portable: it measures the
# pass firing rather than the emitted bytes, so it works on targets where the
# transform is real but object-invisible. The reassoc sub-knobs are exactly that
# case -- they fire identically on x86_64 and i386 (8/3/3/4) while the object
# diff only shows on x86_64.
# A fifth field carries extra compiler flags. The four reassoc sub-knobs are
# MCC_OPTD_ALWAYS, but the strategy they feed is gated by tree-reassoc, which
# came off the shipped ladder to rung 10, so the counter is 0 at every shipped
# level and the delta has nothing to measure. Naming the parent here keeps the
# cell at -O2 and states the dependency, which -O4 would not: that rung turns
# on nine other demoted rows, and they add reassoc folds of their own that the
# off side would then also see (8 instead of 0).
reassoc_assoc|-O2|reassoc|reassoc-assoc|-ftree-reassoc
reassoc_shlshr|-O2|reassoc|reassoc-shlshr|-ftree-reassoc
reassoc_shrshl|-O2|reassoc|reassoc-shrshl|-ftree-reassoc
reassoc_muldist|-O2|reassoc|reassoc-muldist|-ftree-reassoc
bfold_sqrt|-O2|bfold|bfold-sqrt
bfold_sign|-O2|bfold|bfold-sign
bfold_round|-O2|bfold|bfold-round
bfold_minmax|-O2|bfold|bfold-minmax
# The two AST optimizer strategies whose -fno- gate (added by T-lin-10443,
# ast_opt_user_disabled) is cleanly counter-visible: forcing the flag off drives
# the pass count to 0 where it fires by default. tree-loop-im gates ast_licm_temp
# (the ltemp counter) and narrow gates the narrow pass; both fire at -O4 on their
# own optfire subject and vanish under -fno-. The other four gated strategies --
# gcse, tree-dse, tree-copy-prop and sethi-ullman -- are NOT here on purpose: their
# --stats counter reads strategy SELECTION (sf[AST_STRAT_*]), which happens before
# the do_<pass> gate ast_opt_user_disabled sits on, so -fno- suppresses the pass
# but leaves the count unchanged (cse/dse/cprop all read 2->2). cdelta cannot
# measure a gate downstream of its counter; that overlapping-taxonomy set has no
# clean single-counter signal and is deliberately not asserted here.
ltemp|-O4|ltemp|tree-loop-im
narrow|-O4|narrow|narrow
