# Optimizer coverage ledger (T-lin-10466) — the union optimization set of the
# top-20 languages' production compilers (DETAILS#t-lin-10467-lang-opt-catalog,
# 116 items, groups A-G) mapped onto mcc. For an AOT C compiler the completeness
# checklist is items 1-51 (groups A local/peephole, B data-flow/global, C loop)
# plus 71-84 (group E codegen); group D 52-70 is the IPO/LTO tier and F/G are
# structurally out of scope (JIT / language-semantics-specific) but their AOT
# analogs are gap-checked.
#
# Format: <id>|<optimization>|<status>|<evidence>
#   covered  — a partial cell asserts the pass fires; evidence = cell name(s)
#   partial  — mcc does a subset; evidence = cell(s) + why-partial note
#   dev      — implemented but MCC_DEV-only (not on a shipped -O); evidence = cell
#   base     — always-on base codegen, no on/off knob to assert; evidence = note
#   gap      — standard opt with no mcc knob (or shipped OFF); evidence = task id
#   oos      — structurally not applicable to AOT C; evidence = why
# A cell token is an optfire row name (counters*/differs*/levels*/cdelta*/
# defstate*.txt) OR a tests/cli/cases.h case name. coverage-check.sh verifies
# every covered/partial/dev cell resolves and every gap names a real task.
