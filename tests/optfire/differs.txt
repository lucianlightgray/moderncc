# switch-jumptable lowering (id79): a dense switch lowers to an indexed jump
# table under -fswitch-jumptable, a compare cascade under -fno-. The flag is a
# SPECIAL knob whose default reproduces the old env/opt-search behavior, so this
# is o0- and shipped-On-neutral; the differ only shows when the flag is forced.
# -fPIC is REQUIRED: x86_64-Mach-O refuses a jumptable unless pic (switch_jt_dense,
