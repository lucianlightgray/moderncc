# Optional host-local provisioning manifest (T-lin-10388).
#
# These resources are NOT tracked in git: they are large corpora / sysroots that
# each box fetches or symlinks locally (see vendor/). When one is present, cells
# that need it run for real; when absent, those cells mcc_skip_test-stub and the
# suite still reports green -- so a resource that was PRESENT and then VANISHES is
# indistinguishable from a box that never had it, and the loss gets re-recorded as
# a permanent fleet property (the T-lin-10388 defect).
#
# tools/provisioning-detector.sh closes that gap: it AUTO-STAMPS each resource the
# first time it observes it present (stamp kept host-local + untracked under
# vendor/.provisioned/), then FAILS with a named error if a previously-stamped
# resource later goes missing. A resource never stamped on this box is skipped
# (this box genuinely never had it), not failed. So the manifest lists every
# optional resource ANY fleet box may hold; each box only arms the subset it has.
#
# Columns, `|`-separated:  <name> | <path relative to repo root> | <what it enables>
# `-e <path>` is used, so a dangling symlink (target fetched then deleted) counts
# as MISSING, which is exactly the loss we want to catch.
